BLOG · FIRST POST

Designing the "field" that lets an agent explore

The key to agent performance is less about making the LLM smarter, and more about designing a "field" where it can run hypothesis-testing loops efficiently — a slightly paradoxical idea: use the LLM without leaning on it entirely. Leave search, aggregation, computation and simulation to existing systems, and let the LLM focus on controlling the exploration — illustrated with a counterfactual shogi review system. (Japanese)
